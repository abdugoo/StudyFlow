# StudyFlow_full

Полная клиентская часть для исходного API StudyFlow. Backend, модели и миграции не изменены.

## Запуск

Backend запускается из корня проекта по исходной инструкции README.md: настройте PostgreSQL и `.env`, установите `requirements.txt`, выполните `alembic upgrade head`, затем `uvicorn app.main:app --reload`.

В другом терминале:

```sh
cd frontend
npm ci
npm run dev
```

Откройте http://localhost:5173. Требуется Node.js 22 или новее. Frontend отправляет запросы на `/api`; Vite проксирует их на `http://127.0.0.1:8000`, поэтому изменения CORS в backend не нужны. Для другого адреса скопируйте `frontend/.env.example` в `frontend/.env.local` и задайте `API_TARGET`.

## Возможности

- Регистрация студента или преподавателя; вход по OAuth2 password flow.
- Каталог, поиск по названию, сортировка, сведения о курсе и участниках.
- Запись студента на курс, список своих курсов, выход из курса.
- Создание, изменение и удаление собственных курсов преподавателем.
- Просмотр, редактирование и удаление профиля.
- Адаптивный русский интерфейс, диалоги с фокусом, состояния загрузки, ошибок и пустых списков.
- JWT хранится в sessionStorage текущей вкладки, очищается при выходе и ответе 401.

Интерфейс показывает реальные данные. Если backend не запущен, выводится сообщение с повторной загрузкой. В исходном API нет уроков, видео, оплаты, оценок или прогресса — эти функции не имитируются.

## Проверка и сборка

```sh
cd frontend
npm test
npm run build
npm run preview
```

Сборка находится в `frontend/dist`. Для production раздавайте её статическим сервером, направляя `/api/*` на backend с удалением префикса `/api`. `API_TARGET` используется сервером Vite, а не статической сборкой. Не публикуйте секреты backend в переменных frontend.
